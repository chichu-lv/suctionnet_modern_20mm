## 代码管理

- `main` 保持可阅读、可测试的主线。
- 新算法、标签公式或数据格式改动使用独立分支和 Pull Request。
- 代码不覆盖 SuctionNet 官方源文件；生成数据存储于外部 `$OUT`。
- Python 变更需运行 `pytest -q`；数据标签变更需附至少一个可视化示例和指标对比。
- 不将大型原始数据、隐私配置、训练权重默认提交进 Git。
