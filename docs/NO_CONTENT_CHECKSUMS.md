## 项目约束

从本次修复起，项目不计算或验证 SHA-256，不以另一种内容校验和替代原来的全文件扫描。此约束覆盖数据构建与读取、teacher 缓存、checkpoint 保存/恢复、运行监督器、备份、日志导出、性能脚本和可执行参考程序。开发要求见根目录 [AGENTS.md](../AGENTS.md)，回归门禁为 `tests/test_no_sha256_verification.py`。

过去实验 JSON 中已经保存的摘要值属于历史元数据，不再作为当前程序的必填字段或接受条件；读取旧记录时忽略，新输出递归去除。历史结果的 loss、准确率、时间、模型权重和实验划分不因本次修复改写。Git commit/blob ID 继续用于仓库版本引用，模型的确定性随机相位也不属于文件校验。

## 当前实际检查

| 对象 | 保留的检查与记录 | 不提供的能力 |
|---|---|---|
| 数据和 NPZ | 文件可解析、字段、shape、dtype、有限性、标签 mask、实际查询 ID/p/n、已知物理配置、split/group/capture ID | 检测任意等长字节改写或自动证明资产内容相同 |
| 运行配置 | 保存并直接比较小型可读配置，包括训练语义、预算、精度和后端选择 | 以路径或文件大小证明配置内容 |
| checkpoint | 原子写入、generation/attempt/step、文件大小、可加载状态、模型键及形状、optimizer/RNG/sampler/预算一致性 | 内容寻址或密码学完整性认证 |
| 日志 | 已提交字节长度、记录可解析、run/attempt ID、成功更新及样本预算 | 检出等长且结构仍合法的日志改写 |
| 备份 | 固定 generation、预期长度、源路径范围、原子发布、完成标记和运行所有权 | 复制完成后再扫描整文件计算摘要 |
| 原生扩展 | 显式 source version、ABI、compiler、编译参数、Python cache tag、二进制文件名 | 通过文件内容推断版本 |
| 复现与性能对照 | 有界的实际 tensor/array 直接逐项或逐位比较；模型结果按明确容差比较 | 用 shape 或文件大小冒充数值等价 |

文件路径和 `size_bytes` 只用于定位及发现缺失/截断。小型配置直接比较不需要再次读取大型资产。正常训练仍会读取和解压样本一次，备份仍会复制实际字节；删除的是为摘要重复读取同一份内容的步骤。

## 新旧记录兼容

单物体新 manifest 使用 `suction20.instance_manifest.v4`，仍接受旧 v3。旧缓存若没有结构化 teacher physics，记录为未知；不能根据旧摘要猜测参数，也不单因缺摘要要求全量重算。实际 p/n 对应、标签公式和有限性检查仍执行，双方 physics 已知时直接比较。

新版本生成的 checkpoint 继续支持完整暂停/恢复。旧记录只在能从实际保存的配置、模型状态和剩余元数据确认兼容时恢复；不会为满足旧字段重新计算摘要。旧目标域 sampler 若只保存无法还原成员含义的不透明 ID，则明确拒绝精确续训，改用已有权重初始化入口建立新的微调运行。禁止编造映射后声称采样顺序无损恢复。

CD-009 一次性 performance 迁移流程早已退出当前代码，这次不恢复它。带旧迁移收据的档案保留作历史记录，不应删除收据强行续训，也不应照抄历史文档中的摘要命令。具体支持边界见 [CHECKPOINT_POLICY.md](CHECKPOINT_POLICY.md)。

## 开发检查

```bash
python -m pytest -q tests/test_no_sha256_verification.py
```

该门禁识别可执行源码中的算法调用及外部校验命令，而非禁止文档讨论、历史 JSON 字段或读取旧字段后丢弃的兼容代码。新增读写功能继续用实际结构、语义和事务 ID 检查，不增加隐含的大文件二次扫描。
