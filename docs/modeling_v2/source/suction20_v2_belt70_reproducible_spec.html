01. 已确认的 5 项设计决策与论文级三面板方法图

D1 · 相机与推理形态：固定顶视俯拍 + 按单个目标物品推理

重力方向 g_cam 与传送带承载平面恒定已知；采用“目标实例 + 外扩 75 mm 局部背景”单实例推理，无多实例重叠冗余，较全场景 E5 提速 3–5× 且保住传送带/邻物防碰。

D2 · 透明瓶中心掉深修复：模型内置空洞自修复能力（不强依赖外部独立修复模型）

预处理对实例内缺深区做零训练局部几何预填（Zero-Touch 不改有效深）并打上 is_raw_valid / hole_dist 标记；骨干内部增设 Δz_hole 表面修正头，未来同事的专用修复模型就绪后可直接无缝替换输入。

D3 · 多源数据推进排期：P0：SuctionNet 瘦身 + ClearPose 抽帧；P1：MetaGraspNetV2（同步）+ 压扁瓶合成（待调研）

首轮先用 P0 两库快速闭环训练与内置补洞验证；MetaGraspNetV2 同步做 ~100 瓶罐类物体精选与 R20 重算；压扁瓶合成按需以极简 FFD 管线补齐形变长尾。

D4 · 碰撞包络与输出头：碰撞包络缩短至 70 mm（保留 cup+mount，裁掉 70–150 mm approach）；启用精简解耦输出头

外扩 75 mm 裁剪恰好完整覆盖 ρ≤28 mm、z≤70 mm 碰撞包络，零截断；输出头定型为 q_SW (S×W)、p_free (1−C_70mm)、n_hat、Δz_hole（及微调残差头 Δ_θ），推理期可按 α 调节防碰松紧。

D5 · 预训练与偏好微调节奏：先完成多源预训练；微调集已人工复核 ~400 帧并持续扩充，原始数据与历史 A 位姿齐全

400+ 帧量级严格采用“冻结 3D 骨干 + 轻量残差头 Δ_θ + 50%–70% 源域回放”；好点 B 仅存 2D 像素 (u_B, v_B)，经内置补洞转 3D 并扩成 5–8 mm 正邻域 B⁺ 与历史差点 A 构成平滑偏好对。

[P0] SuctionNet-1B（瘦身过滤 + 双相机 + 合成挖洞）

定位：P0 主力几何与遮挡先验；在线施加合成中心掉深训练内置修复分支

已有资产：完整具备 R20 Producer 所需全部 5 项资产（88 个物体 CAD 及已有 seal_r20 缓存、100 训练场景精确 6DoF 位姿、桌面重力坐标系、双传感器）。

缺失项与风险：① 每场景 256 视角高度冗余（E5 实测 2,880 步即达验证峰值 13.12%，后续掉回 12.02%）；② 含大量深埋多层堆叠；③ 缺少真实透明瓶中心掉深。

  1. 视角等距抽帧：scene 0–99 每场景从 256 视角等距抽 24–32 帧（步长 8–10），同步纳入 Kinect 视角；验证集按 scene 严格切分，严禁同场景跨 split。
  2. 过滤极端多层堆叠：对每个实例计算可见表面占比与上方 z∈[0, 70] mm 邻近异物点占比，剔除被深埋底层（如顶部覆盖率 > 50% 或邻近 40 mm 柱体阻塞过重）的实例，只留表层、半遮挡、贴桌样本。
  3. 将碰撞包络配置中的 approach 段 [0.07, 0.15] 移除，按 V2-Belt70（cup [-2,25] + mount [25,70] mm）重算或筛选 C_70mm。
  4. 训练期在线施加“合成中心透明挖洞（Synthetic Hole Dropout）”：在目标实例内随机生成 1–2 个椭圆空洞（短轴 12–32 mm），将原始有效深度置空作为空洞输入，用挖洞前原始深度监督 Δz_hole。

[P0] ClearPose（轨迹强降采样版）

定位：P0 核心透明瓶数据源：提供真实透明掉深分布 + 63 个透明 CAD 的 R20 真值与 Δz_hole 真值

已有资产：同时具备 63 个真实扫描透明物体 3D CAD（大量塑料/玻璃瓶）、每帧精确 6DoF 位姿、逐帧实例掩码、真实传感器掉深图 Raw Depth 与 CAD 渲染的真值完整深度 Rendered GT Depth。

缺失项与风险：① 原库为连续视频流（>35 万帧），相邻帧极度重复；② 部分子集无标准桌面外参，需通过场景外参或背景 RANSAC 恢复承载面与重力方向，剔除非平面支撑场景。

  1. 按序列/场景维度切分 Train/Val；剔除无承载平面的场景，每条视频轨迹按位姿变化或帧步长等距抽 10–20 帧，将总帧数压到 ~2,200 帧高多样性样本。
  2. 对 63 个透明物体 CAD 一次性运行离线 seal_r20（Poisson 采样 + R=20 mm 密封性评估），生成与 SuctionNet 完全一致的 seal_r20 缓存（63 物体离线计算量很小）。
  3. 通过统一 Adapter 导入相机内参、6DoF 位姿、恢复出的承载平面与实例掩码，调用 V2-Belt70 R20 Teacher 计算 S20、W20、C_70mm 与 gt_normal。
  4. 保留真实 Raw Depth 作为网络输入，用 Rendered GT Depth 与 CAD 表面作为内置空洞修复头 Δz_hole 及补洞区 gt_normal 的真值监督。

[P1] MetaGraspNetV2（仿真子集 · 瓶罐类精选）

定位：P1 扩充物体几何形态多样性（各类塑料瓶、软包、盒罐、半杂乱摆放）

已有资产：仿真子集完整提供 RGB-D、内参、实例与 Amodal 掩码、约 989 个物体 CAD、精确 6DoF 位姿与世界系重力/承载面。

缺失项与风险：① 自带抓取标签为小半径/Dex-Net 口径，严禁直接混训；② 989 个物体全算 R20 Poisson Seal 离线算力过高，必须先精选子集；③ 真实子集 CAD 对齐不全，不建议投入清洗成本。

  1. 物体级先筛后算（算力止损）：从 989 个物体中优先筛出尺寸适合 R=20 mm 吸盘的瓶、罐、盒、圆柱及不规则容器约 80–120 个核心物体，只对这批物体跑离线 seal_r20。
  2. 仅保留包含上述精选物体的非极端堆叠仿真帧，每场景抽 2–4 帧（控制总量 ~2,500–3,000 帧）。
  3. 经与 ClearPose 相同的统一 Adapter 导出中间格式，丢弃原库抓取分，全部用 V2-Belt70 R20 Teacher 重算标签，并在线叠加合成透明挖洞增强。

[P1] 轻量压扁瓶 + 传送带合成（待调研路线）

定位：P1 专门补齐所有公开库都缺失的“压扁变形 PET 瓶 + 平面传送带”分布

已有资产：可 100% 原生导出变形后 watertight Mesh、精确 6DoF、恒定顶视传送带平面、少量随机异物半遮挡及干净/退化双深度。

缺失项与风险：待调研选定最省事的离线形变与渲染工具链（不需要做复杂写实光追，几何形态真实 + 掉深分布真实即可）。

  1. 极简形变方案（最省算力）：收集 20–30 个常见饮料瓶/洗护瓶开源 Mesh，用 Python（Trimesh / Open3D）施加随机轴向压扁（单轴缩放 0.35–0.75 + 局部高斯凹陷 + 轻度弯折），导出 ~150 个变形后 watertight Mesh。
  2. 物理投放（PyBullet）：将 1–4 个压扁瓶与 1–3 个简单异物（折纸板、块状杂物）自由落体到水平传送带平面，按固定顶视相机内参渲染深度与实例掩码。
  3. 对每个变形后 Mesh 跑 V2-Belt70 R20 Teacher，并按现场透明瓶掉深统计在渲染深度上叠加空洞与边缘飞点噪声。

3.3 精简解耦输出头规格

输出头监督目标损失函数推理与工程用途
q_SW（吸附物理主头） S20 × W20 ∈ [0, 1] SmoothL1(β=0.05) + 实例内 Top-K 排序损失 核心吸附力评分，吸收 UISN 合并 S/W 经验，消除双头乘积误差放大

04. 两阶段训练配方与 400+ 人工偏好对微调协议

# Stage 1 多源预训练联合损失
L_pretrain = 1.0·L_SW + 0.6·L_free + 1.5·L_normal + 0.5·L_hole_z + 0.1·L_seal_aux
# Stage 2 偏好对残差微调损失（冻结 3D 骨干与 BN）
s_final(x) = logit(q_SW(x) · p_free(x)^α) + Δ_θ(x)
L_pref(B⁺, A⁻) = -(1−ε)·log σ((s(B⁺) − s(A⁻) − m)/τ) − ε·log σ((s(A⁻) − s(B⁺))/τ)
L_finetune = L_pref + 0.8·L_source_replay + 0.02·‖Δ_θ‖² (ε=0.08, m=0.25, τ=1.0)

透明瓶中心空洞候选覆盖与表面误差 原始未补洞点云（中心覆盖率接近 0%） 透明瓶中心空洞区有效候选覆盖 ≥ 90%，ClearPose 空洞区 Δz_hole 中位误差 < 4 mm 定量验证内置空洞修复真正救回了透明瓶中心区域，且没有把曲面补偏。

05. 代码实现易错细节清单（10 条高危陷阱与测试断言）

P01 · [数据与标签 / 高危] candidate_row 与 candidate_id 混用错位

易错写法：用 camera-point 文件里的 candidate_id（原 Mesh 顶点索引，如 2476）去索引 seal_r20["scores"] 或 seal_r20["normals"]。

真实后果：越界报错或静默读到完全错误顶点的 Seal 分数与法向，训练信号彻底污染（原仓库 DATA_SCHEMA.md 已专门警示）。

正确实现规范：索引物体 Seal/Wrench/Collision 数组时严格使用 0-based 的 candidate_row；candidate_id 仅用于追溯原始 CAD 顶点。

单元测试断言：断言 matched_xyz 与 transform(seal.points[candidate_row], T_cam_obj) 的欧氏距离 <= match_radius_m (5 mm)。

P02 · [数据与标签 / 高危] 把 gt_valid=False 的未匹配点误当负样本 0 算损失

易错写法：对整张点云的所有前景点直接算 MSE/SmoothL1(q_pred, gt_SW)，忽略 gt_valid 掩码。

真实后果：大量本应为高分、仅因采样密度未命中 <=5 mm 匹配半径的表面点被强行压向 0，模型输出整体坍缩偏低。

正确实现规范：质量头与碰撞头损失严格只在 gt_valid=True 点上归约；法向损失严格在 quality_valid & axis_finite 点上归约。

单元测试断言：构造含 50% gt_valid=False 且将对应 gt_SW 填为 NaN 的合成 batch，断言前向/反向 loss 有限且梯度不受其影响。

P03 · [数据与标签 / 高危] MetaGraspNetV2 直接混用原标签或对 989 物体全量算 Seal

易错写法：直接读取 MetaGraspNetV2 自带的吸盘分数与 SuctionNet 混训，或者对全库 989 个 CAD 全跑一遍 R20 Poisson Seal。

真实后果：混用原标签会导致 R10/Dex-Net 口径与 R20 严重冲突；989 物体全量算 R20 Seal 会浪费数天离线算力在无关小零件上。

正确实现规范：先按尺寸（包围盒最大边 >= 50 mm）与形态筛选 80–120 个瓶/罐/盒/容器类物体，只对精选子集跑 V2-Belt70 R20 Teacher。

单元测试断言：核查所有多源缓存 metadata 中的 radius_m=0.020 与 envelope_max_z_m=0.070 一致，禁止跨口径混装。

P04 · [数据与标签 / 中危] ClearPose / SuctionNet 按帧随机切分造成视角泄漏

易错写法：把 ClearPose 视频帧或 SuctionNet 256 视角打乱后 8:2 随机划分 Train/Val。

真实后果：验证集包含与训练集仅差几度视角的同一场景，验证指标虚高到 95%+，实际泛化能力完全失真。

正确实现规范：严格按 scene_id / video_sequence_id 分组切分；目标域 400+ 偏好对同样按采集批次/独立瓶子切分验证集。

单元测试断言：断言 set(train_scene_ids).isdisjoint(set(val_scene_ids)) 为 True。

P05 · [透明补洞与几何 / 高危] 内置补洞覆盖原始有效深度（违反 Zero-Touch）或穿透传送带

易错写法：把整个瓶子 ROI 全部替换成平滑/插值深度图，或不做传送带平面深度下界截断。

真实后果：原本清晰的不透明瓶折痕/凹陷被平滑抹平，20 mm 密封评分误报高分；大空洞插值外推可能掉到传送带背面以下。

正确实现规范：严格执行 D_out = is_raw_valid ? D_raw : clamp_above_belt(D_fill)；Δz_hole 残差头同样只加在 is_raw_valid=0 的补洞点上。

单元测试断言：断言所有 is_raw_valid==1 像素在预处理与 Δz_hole 修正后坐标最大绝对差为 0.0，且所有补洞点到传送带高度 >= 2 mm。

P06 · [透明补洞与几何 / 高危] 外扩局部裁剪小于 70 mm 包络导致 mount 区点云被截断

易错写法：按目标物体紧致包围盒仅外扩 30 mm 裁剪局部点云，然后去算 z∈(25, 70] mm、ρ≤28 mm 的 mount 区碰撞。

真实后果：瓶子侧面斜着贴近的邻近垃圾或上方 50–70 mm 处的障碍物被提前裁掉，模型学成“盲目无碰撞”。

正确实现规范：计算目标 3D AABB（含补洞后范围）并向 6 个方向统一外扩 ≥ 75 mm（同时保留传送带表面点），确保 70 mm 碰撞包络内零截断。

单元测试断言：对任意目标表面点 p 与任意合法外法向 n，断言圆柱 (ρ≤28 mm, z∈[-2,70] mm) 完整落入局部裁剪 AABB 内部。

P07 · [透明补洞与几何 / 高危] 候选采样器在透明瓶上仍被边缘原始点占满，中心补洞区无种子

易错写法：沿用只在原始有效点上做 FPS 的候选采样器，或把全部补洞点与原始点不加区分混抽导致极端失衡。

真实后果：若只在原始点抽样，即便做了补洞，透明瓶正中心依然没有候选种子进入接触头打分。

正确实现规范：采用双配额分层候选池（256 种子）：在实例 2D 包围盒内按 bit-reversed Morton 16×16 网格分层采样，网格内若中心为补洞点同样允许入池，并记录该候选的 is_raw_valid 与 hole_dist_norm。

单元测试断言：在中心挖出半径 25 mm 圆洞的合成瓶测试样例上，断言至少 15% 候选种子落在原空洞区域内。

P08 · [骨干与接触头 / 高危] 外向法向与接近方向符号翻转，以及切向坐标基极点不连续

易错写法：训练时用外向法向，推理算碰撞圆柱时按接近方向反向取 z；或在接触头直接把任意构造的局部切向 (u, v) 坐标喂给 MLP。

真实后果：接触包络朝瓶子内部反插导致碰撞率飙升；(u, v) 在 n_z 接近 ±1 处跳变破坏旋转等变性（Route A/B 复盘核心教训）。

正确实现规范：全管线统一定义 n 为指向物体外部的单位法向（固定顶视下 dot(n, -ray) > 0）；lip 环带仅使用旋转不变的 (ρ, h) + 8 扇区循环 Conv1d / 圆谐波，不输入任意切向坐标。

单元测试断言：将同一测试实例绕相机 Z 轴旋转 90° 与 180°，断言各候选点 q_SW 与 p_free 预测差值 < 1e-4。

P09 · [偏好对微调 / 高危] 人工点击透明瓶中心好点 B 被 <=5 mm 原始深度门控静默丢弃

易错写法：沿用原仓库 score_at_pose 的“查询点 5 mm 内必须有有效原始深度点”检查来处理目标域人工点击点 B。

真实后果：最值钱的透明瓶中心纠偏样本全部被静默 skip，微调集实际上只剩不透明瓶样本。

正确实现规范：标注工具直接存 RGB 像素坐标 (u_B, v_B)；微调查询时走内置几何预填 + Δz_hole 修正后的统一表面点云，并取半径 5–8 mm 同面邻域 B⁺ 聚合打分（历史差点 A 保持原记录 (p_plan, n_plan) 不篡改）。

单元测试断言：构造 B 落在深度全 0 空洞中心的真实目标域样本，断言 B⁺ 有效点数 > 0 且偏好损失产生非零有效梯度。

P10 · [偏好对微调 / 高危] 400 帧小样本微调未冻结 SpConv BN 或未做源域回放

易错写法：微调期直接 model.train() 解冻全网并只喂 400 帧目标域偏好对。

真实后果：BatchNorm running stats 被小 batch 瞬间带偏，且网络为迎合 400 对局部点击迅速忘光源域 3D 几何常识，复现之前“微调后观感反而不如预训练”的倒退。

正确实现规范：微调期强制 backbone.eval() 且冻结全部 BN running stats/affine，仅更新轻量残差头 Δ_θ，每步强混 50%–70% Stage 1 源域回放样本。

单元测试断言：对比微调 100 步前后骨干全部参数与 BN running_mean/var，断言最大绝对变化 == 0.0。
