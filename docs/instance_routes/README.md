# 单物体吸取路线 A 与路线 B 工程实施规范

本规范将两条路线收敛到同一个任务：输入一个实例的 RGB、观测深度与重力，针对明确的接触中心和有向轴预测 `S20`、`W20`、`Q_SW20` 与目标域任务成败，输出带坐标约定的吸取姿态。A 使用稀疏 3D 主干；B 使用整物体 2D 上下文与候选切平面接触图。两者共享实例划分、物理标签、动作监督和评价协议。

**交付状态：工程设计与实现验收规范，附可运行的 NumPy 几何和数据契约参考工具。A/B 新模型、数据构建器、训练器及 TensorRT engine 尚未实现。** 当前已有的 E5 训练脚本不接受这里的新输入和 `Q_SW20` 目标，不能用下面的设计配置直接启动 A/B 训练。文档明确列出实现接口和真实可运行命令。

基线为 [`87f29d2`](https://github.com/chichu-lv/suctionnet_modern_20mm/commit/87f29d29bea8fa5153d6df3f8253d9ced9e4b441)，即 2026-11-18 清理历史 checkpoint 迁移兼容后的主线。本文的默认超参数是新路线的初始配方；已有实验事实与新设计假设分开记录。

## 2 两条路线的统一版本

| 维度 | A 单实例稀疏点云 | B 单实例 2.5D 双层图像 |
|---|---|---|
| 完整观测 | 原分辨率实例点、对齐 RGB、法向、完整重力 | 同样的实例观测与标定 |
| 主干输入 | 最多 2048 个不重复点，12 维，2 mm 体素；有效掩码独立 | 全物体 128×128 上下文，13 通道；记录仿射和真实米制坐标 |
| 精细接触支持 | 完整可见实例点，独立于 2048 主干点 | 每候选 64×64 切平面局部图，1 mm/格、10 通道 |
| 模型 | 新的单实例 SpConv ResUNet14 封装 | ResNet-18 编码器与 U-Net 解码器，加小型 2D 接触编码器 |
| 候选 | 最多 256 个同一规则产生的有效姿态 | 同一组最多 256 个姿态，局部图分块 64 个处理 |
| 物理范围 | core 0–10 mm、inner 10–18 mm、lip 18–22 mm | 同一径向分区；显式掩码聚合，普通空洞卷积可作上下文但不充当精确圆环 |
| 输出 | `q_sw`、`seal`、`wrench`、`log_laplace_scale`、`task_logit` | 同左 |
| 历史动作 | 直接 `score_at_pose(p_plan,n_plan)` | 用该历史点和轴构造局部图，再直接评分 |
| 依赖 | PyTorch、固定版本 spconv；可复用原生 CPU 几何 | 学习部分为标准 2D PyTorch 算子；几何前处理仍需反投影和局部栅格化 |
| 延迟状态 | 15–30 ms 仅保留为初始期望，尚未测量 | 2–5 ms 尚未验证，不能据主干算子类型保证全链路达到 |
| 实施定位 | 优先落地，复用现有 3D 物理与评分基础设施 | 在同一数据和评价协议下验证的部署候选 |

B 的“物理尺度归一化”落实在候选接触切平面，不再要求整件物体、所有深度和倾角都被一张固定大小图精确表示。这样保留纯 2D 学习网络，同时明确增加了局部图构造成本。A/B 都不在物理目标中加入碰撞项，执行系统的其他约束不由 `Q_SW20` 代表。

## 3 对原方案的关键修正

| 原设计中的表述 | 修订后的工程定义 |
|---|---|
| 单物体采样后“100%覆盖”，解决约25%优质实例遗漏 | 每物体单独分配候选预算，收益由实例无输出率、好候选覆盖和第一名选择率测量；现有数据不支持25%的因果结论 |
| 2048 点同时承担骨干与密封环几何 | 2048 只控制骨干成本；法向、薄唇口与覆盖来自完整可见点 |
| 可见点均值就是物体质心 | 仅作平移原点和形状描述；Wrench 保留冻结 teacher 的完整候选中心代理 |
| `g_z` 足以表示重力 | 保存相机系完整三维单位方向和来源；目标现有数据来源是传送带平面法向近似 |
| 去掉 `C` 只是移除外部碰撞 | 旧 `C` 也含目标自身碰撞；新 SW 明确不包含该整体碰撞判定 |
| 固定平滑法向可自动与旧标签100%对齐 | 必须在新的接触点、同一有向轴上重新计算 S/W；固定法向本身不改写旧标签 |
| 现有模型已有方差头 | 当前代码没有；新加 Laplace log-scale 头，名称与损失对应 |
| 20 mm 邻域共享真实动作成败 | 一条动作只产生一个条件 logit 与一个 BCE；邻域用于输入特征聚合 |
| 中位深度仿射使所有位置恒为2 mm/px | 只对参考平面成立；真实深度带来 `Z/Z_ref` 比例，倾斜表面还受投影影响 |
| 膨胀率10的3×3卷积就是20 mm圆环 | 轴向采样在20 mm，角点在28.28 mm；改用显式米制环掩码 |
| 平滑法向唯一决定6-DoF | 接触点与轴决定5个自由度；另固定 roll 规则及 contact→TCP 变换 |
| E5 step2880证明新模型14万实例即可最优 | 旧预算单位是全场景观测；14万是新路线共同初始上限，选模仍用固定验证 |
| `P_task q^0.5` 是成功概率 | 它是可选排序启发式；默认源域按 q、微调后按任务分数，分别输出原始分量 |

## 4 已有结果支持哪些判断

[E5 方法比较](../SUCTIONNET_METHOD_COMPARISON.md) 已表明排序与候选质量应分别考察。完整 R20 测试的每实例无候选率约为 Seen 0.0377%、Similar 0.0134%、Novel 0.0218%；“有输出”并不等于“有可吸取候选”。不能把场景 Top-50 覆盖、每实例无候选率或目标成败分类指标互相替代。数据见 [diagnostics.json](../experiments/COMPARISON-20261118/diagnostics.json)。

[目标域数据汇总](../experiments/CD010-20261117/finetuning/data/summary.json) 有 1676/399/87 条训练、验证和测试动作；它们关联 `planned_pipeline_contact`，并非已独立测量的真实接触位姿。旧 E5 的验证改善只说明已有任务头在固定历史动作上的成败区分改善，不能作为 A/B 新架构的已测收益。

单实例预算、RGB、去碰撞目标、固定法向和新结构同时改变了模型条件。首轮 A/B 是工程路线比较；不得把全部增益归因于其中一个模块。无需为当前设计增加大规模消融矩阵，先把共同数据、固定姿态与输出协议做对。

## 5 当前仓库能复用什么

| 现有代码 | 可复用部分 | 新路线必须显式改变的部分 |
|---|---|---|
| `models/backbones/spconv_resunet14.py` | 固定第三方骨干与稀疏坐标封装 | 首层当前固定8通道；A新增12维封装，不能假装完整E5权重同结构 |
| `models/suction20net.py` | 编码/任意姿态查询思想，确定性特征关联 | 新的模型类、query schema、三接触区、头和对象上下文 |
| `suction20/eval_r20.py` | 在真实姿态计算 S/W 的 teacher 参考 | 新缓存和 SW 指标；不用 `gt_B/C` 反推 |
| `suction20/target_dataset.py` | 规划点/有向轴、实例与split约定 | RGB、内容hash、单实例观测以及新模型输入 |
| `suction20/finetuning.py` / `losses.py` | 200+800阶段、源回放、单动作 BCE | 原入口限制gt_B；新增SW契约、loss与参数组 |
| `suction20/runner.py` | 运行与状态保存基础设施 | 当前构造器固定Suction20Net；A/B注册与新训练入口 |
| [checkpoint政策](../CHECKPOINT_POLICY.md) | 同身份恢复、初始化与resume分开 | A/B另设架构和输入身份，不恢复已退役迁移兼容 |

这些文件的审查版本均为本页首部固定 SHA；网络具体映射和新增文件列表见各路线文档。这里复用的是经过核对的代码组件与数据约定，不代表已完成新接口接线。

## 6 实施顺序与完成定义

1. 固定实例和动作清单，完成同姿态 SW 缓存；两条路线读取相同 query。
2. 接通 A 的单实例编码与任意姿态评分，先用一份真实样本核对 teacher 和 mask。
3. 接通 B 的全局图、切平面局部图和同一评分接口；通过几何参考例和原始姿态回读。
4. 按共同的14万实例暴露与1000步目标微调配方训练；固定验证节点选模。
5. 保存完整逐动作/逐候选结果，以 SW、历史动作分类和实际耗时判断路线差异；公共 R10/R20 仍使用原协议。

“设计完成”“合成几何参考通过”“真实数据链路通过”“新模型训练完成”“部署延迟达标”是不同状态，记录在各自运行报告中。本次交付完成设计与合成几何参考；后续实现不以恢复历史 checkpoint、重做旧全量数据工程或补齐实测物体 COM 为前置。

## 7 一手资料

- 仓库设计依据：[模型与方法比较](../SUCTIONNET_METHOD_COMPARISON.md)、[数据准备接口](../TARGET_FINETUNING_DATA_REVIEW.md)、[当前模型使用](../MODEL_USAGE.md)。
- [OpenCV 相机模型](https://docs.opencv.org/4.7.0/d9/d0c/group__calib3d.html)：投反影、内参与坐标变换。
- [PyTorch Conv2d](https://docs.pytorch.org/docs/2.15/generated/torch.nn.Conv2d.html)：dilation是离散采样间隔。
- [PyTorch grid_sample](https://docs.pytorch.org/docs/2.15/generated/torch.nn.functional.grid_sample.html)：像素中心、插值和CUDA反向的确定性限制。
- [TensorRT GridSample](https://docs.nvidia.com/deeplearning/tensorrt/10.x.x/_static/operators/GridSample.html)：算子类型与输入形状支持；不能由单算子支持推定完整导出已通过。
- [Kendall 与 Gal，2017](https://arxiv.org/abs/1703.04977)：异方差观测噪声与模型不确定性的区别。数学说明不要求升级仓库已记录的PyTorch版本。
