# 路线 A/B 结构复核与修订记录

本次审查针对 PR #8 初稿 [`e495fd8`](https://github.com/chichu-lv/suctionnet_modern_20mm/commit/e495fd89678b5f696e1819437fef5ced5103aa57)，对照生产代码基线 [`87f29d2`](https://github.com/chichu-lv/suctionnet_modern_20mm/commit/87f29d29bea8fa5153d6df3f8253d9ced9e4b441)。结论是：B 的两处结构冲突和定位偏移需要重做；目标自碰必须恢复；其余问题需分别修正表示、控制预算或澄清已有约束。当前修订仍是设计与可运行数学/schema参考，不是已实现模型或性能测量。

## 1. 逐项结论

| 指出的问题 | 核验结果 | v2 决策 |
|---|---|---|
| B 解码到128²却只全局池化，没有 Fq | 属实。解码器不是数学上完全无作用，但没有用于位置查询，成本与用途不匹配 | 删除 U-Net；从 encoder 的两个中间层按 query 取 Fq，末层另池化 G |
| 5.4分区池化与6整图8²池化冲突 | 属实。stride2不等于必然抹去所有纹理，但不能保证4mm唇口的独立表征 | 一次原分辨率纹理stem；18/20/22mm分别读取并按区域聚合，不再每query下采样局部图 |
| B仍有全点PCA、栅格化和256份局部CNN | 属实，违背提速出发点 | 共享organized法向、图像候选、批量投影环带采样；不建B的3D空间索引 |
| argmin基切换造成90°跳变 | 跳变属实，但角度一般不是固定90°，也不一定错18槽 | A去掉人工切向x/y；B固定坐标图、共享环向编码与循环池化；工具roll单独定义 |
| 144扇区量直连MLP易过拟合 | 18432个槽位权重计算属实；是否实际过拟合尚无实验 | 取消有序扇区flatten，消除不必要的绝对角度槽位参数 |
| 全量PCA与teacher重算太重 | 结构风险属实，尚未测出具体毫秒/小时 | 默认移除PCA；训练128查询，64可选；实例teacher按需缓存并先测成本 |
| 去总碰撞丢失目标自碰 | 属实，而且应修改质量目标 | `Q_inst=S*W*(1-C_self)`，保留SW诊断，去除外部项 |
| A 10mm特征关联截断 | 风险成立，400mm宽本身不能证明大量失效 | 最多3个半径内邻居，测覆盖；raw RGB/几何旁路，扩大点数须显式配置 |
| 小batch BN漂移 | 风险成立，但原共同规范已要求微调冻结BN | B新结构统一GN；A/既有BN必须在train()后重新eval并核验buffers |
| 单点动作BCE对执行误差敏感 | 风险成立；单点BCE对“规划命令成败”语义本身正确 | 默认保持一次BCE；2mm/2°一致性正则作为关闭的试验选项 |

## 2. B 的最小有效结构

新的 B 保留两种互补证据，二者每实例只编码一次：

- 全物体128×128、13通道的 ResNet-18 encoder，保留中层位置特征 Fq 与末层全局 G；删除 U-Net。
- 原分辨率实例 ROI 的轻量 stride1 纹理stem，输出16通道；不用128²缩图承担细唇口纹理。

每个查询在自己的 `(p,n)` 平面上定义半径 `[0,5,9,10,14,17,18,20,22] mm`、72角度的采样位置，投影到共享图像特征。半径0只读一次，共577个不同采样槽位/query；256查询对应147712个读取位置。该数量不等于实际不同像素数，也不能换算为已测延迟。共享环向小网络后分别汇总 core/inner/lip，和 Fq/G/查询描述融合。

投影点只是“预期接触平面上的取样射线”。必须读取真实同实例深度，再计算实际高度、半径、法向与缺测mask；不能把投影圆在图内就当作表面存在。RGB细节受原相机像素采样限制，1个像素不天然等于1mm；反复采样不能增加真实分辨率。遮挡、多层和隐藏几何仍是单视图限制。[完整B合同](ROUTE_B.md)

旧三层局部CNN按文档维度计算，每query为：

```text
32² × 10 × 16 × 3² = 1,474,560 MAC
16² × 16 × 32 × 3² = 1,179,648 MAC
 8² × 32 × 64 × 3² = 1,179,648 MAC
合计 3,833,856 MAC/query；256query约0.981 GMAC
```

这是静态乘加计数，不含GN、激活、构图与全局网络。原设计允许chunk64，不能说必须串行调用256次GPU；它仍然需要256份局部编码工作。v2取消这项成本，但其共享图像stem、投影读取及环向编码仍要实测，不能据此承诺2–5ms。

B的实现目标是“无稀疏3D卷积、无空间树、无逐候选栅格/CNN的图像网络”。深度转XYZ和小批量投影算术仍存在，任意历史轴也仍通过query输入条件化。如果只用一个无条件像素热力图，它只能表示固定观测轴；那会丢失历史轴一致性，因此不把这一更强限制伪装成已同时满足的条件。

## 3. 坐标基问题的数值反例

只有当 x/y 是最小绝对法向分量时，`abs(nx)=abs(ny)` 才是二者的选择边界。若两者都不是最小项，基不会在那里切换。对 x→y 切换，在极限相同 n 上：

$$
\cos\Delta\theta=\frac{-n_xn_y}{\sqrt{1-n_x^2}\sqrt{1-n_y^2}}.
$$

取 `n1=(0.199999,0.200001,-sqrt(0.919999999998))`，交换前两项得到 n2。法向仅相差约0.000162°，旧 e1 却相差约92.388°。这解释了为什么“每次都是90°”不准确，也说明风险并不因数值限定而减轻。[可运行反例](reference/revision_contract.py)

A 学习输入改成 `rho,h,n_obs·n,d_t·g,n_obs·g` 等不依赖切平面参考轴的量。B使用固定相机±Z两坐标图来避开原x/y选择边界；接近主图反向极点时仍需要显式换图。环向卷积共享权重，之后沿角度池化，对整数循环移位不变；对任意连续相位与插值误差仅近似稳健，训练相位增强也不是严格连续旋转不变性的证明。

吸盘接近轴与工具roll分开。静态输出可以保留确定性roll用于序列化；连续机器人运动由工具/轨迹约束选择平滑roll，不能直接把无状态基补全当作运动连续性保证。冻结teacher的72分箱及其对象系基不随神经输入重构而改变。

## 4. 自碰与离线成本

实际 [seal_at_pose](https://github.com/chichu-lv/suctionnet_modern_20mm/blob/87f29d29bea8fa5153d6df3f8253d9ced9e4b441/suction20/eval_r20.py) 同时返回Seal和 `rho<20mm,h>5mm` 的自身碰撞，轴向无上限。[碰撞包络](https://github.com/chichu-lv/suctionnet_modern_20mm/blob/87f29d29bea8fa5153d6df3f8253d9ced9e4b441/suction20/full_data.py) 还包括目标自身的杯体/安装/接近段及其他物体/桌面。v2保留两个自身分量并更换目标身份，未将旧总flag重新解释为self。

实例teacher不构造外部场景障碍树；完整dense对象、原候选均值和target-only包络索引复用。Seal仍可能是主瓶颈，因为每query扫描完整对象。其无高度截断的环柱不能用22mm小球或网络±40mm窗口替代。训练减至128查询及按需缓存只减少工作量，不能证明精度不受影响。[标签与预算细节](DATA_AND_LABELS.md)

## 5. 小样本监督与执行误差

历史记录只有规划接触位姿，默认task概率解释为 `P(成功 | 观测, 规划p,n)`。未观测执行偏差可以成为该条件分布中的噪声；因此一次动作一次BCE并没有数学错误。空间标注稀疏也不意味着共享网络参数接收不到梯度。

可选2mm/2°微扰用于弱预测一致性，配置默认关闭；幅度是待验证试验值，不冒称实测执行误差。不能跨实例/断层扰动，也不能把一条动作扩增成多个独立成功证据。若改为噪声边缘化，应平均概率再算一次BCE，并让推理使用相同语义；不能用平均logit的sigmoid替代概率平均。源域姿态变化需要重算teacher。[训练细节](TRAIN_EVAL_REPRODUCE.md)
