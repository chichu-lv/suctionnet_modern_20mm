数据与分数的解释

分布仅统计筛选内有 NMS 候选帧的 Top1 各自排序分数，不计算模型准确率。预训练用 q 排序；微调用任务评分排序，两者不是同一种指标，均不能直接解释为真实机器人成功率。历史人工状态属于原生产动作，不能作为本次新候选的成功标签。原系统 score 与 E5 q 定义不同，不直接比较。重力采用已批准的「传送带法向取反」离线近似，相机几何复现原生产数值链，未独立验证物理标定。点云来自观测深度，不是 CAD 或碰撞真值；可视化抽样不改变模型输入、推理结果或几何定义。页面为生成时的静态结果快照。
